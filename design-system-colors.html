디자인 시스템 색상표 — Tailwind·Material·Bootstrap

공식 컬러 코드를 검색하고 클릭 한 번에 복사하세요. 웹세이프 216색도 함께 제공합니다.

💡 Tips

  • Tailwind는 50(가장 밝음)부터 950(가장 어두움)까지 11단계 명도로 구성됩니다.
  • Material Design은 50~900 기본 10단계에 A100~A700 강조색이 추가로 있습니다.
  • 클릭하면 HEX 코드가 바로 클립보드에 복사됩니다.

자주 묻는 질문

이 색상 코드들은 공식 출처인가요?

네. Tailwind CSS, Material Design, Bootstrap 각각의 공식 GitHub 저장소 소스 코드에서 직접 가져온 정확한 값입니다.

웹세이프 컬러란 무엇인가요?

과거 256색 디스플레이 환경에서도 안전하게 표시되도록 각 RGB 채널을 00, 33, 66, 99, CC, FF 6단계로 제한한 216가지 색상 조합입니다.

색상 코드를 어떻게 복사하나요?

원하는 색상 스와치를 클릭하면 HEX 코드가 자동으로 클립보드에 복사됩니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 서버로 전송되지 않습니다.
