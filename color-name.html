자주 묻는 질문

색상 이름은 어떤 기준으로 찾나요?

입력한 색상과 내장 데이터베이스(200개+) 사이의 RGB 유클리드 거리를 계산해 가장 가까운 이름을 반환합니다.

유사도 퍼센트는 어떻게 계산되나요?

RGB 공간에서 최대 거리(약 441)를 기준으로 실제 거리를 환산합니다. 100%면 정확히 일치하는 색상입니다.

HEX 말고 RGB도 입력할 수 있나요?

네, R/G/B 슬라이더와 숫자 입력으로 직접 조절할 수 있습니다. 조절하면 HEX 코드도 자동 업데이트됩니다.

색상 이름 데이터베이스는 몇 개인가요?

CSS 표준 Named Colors 140개와 주요 색상명 60개 이상을 포함해 총 200개 이상의 색상 이름이 내장되어 있습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
