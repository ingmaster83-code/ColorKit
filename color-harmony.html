기준 색상을 선택하면 5가지 색상 조화 이론에 따른 팔레트를 자동으로 생성합니다

기준 색상 선택

색상을 선택하거나 HEX 코드를 직접 입력하세요. 스와치를 클릭하면 HEX가 클립보드에 복사됩니다.

보색 (Complementary) +180°
색상환에서 정반대에 위치한 색으로, 강한 대비와 생동감을 줍니다.
유사색 (Analogous) ±30°
색상환에서 인접한 색으로, 부드럽고 조화로운 느낌을 줍니다.
삼색 (Triadic) +120° / +240°
색상환을 세 등분한 색상들로, 균형감 있으면서 다채로운 배색입니다.
분보색 (Split-Complementary) +150° / +210°
보색 양쪽의 색상을 사용해 보색보다 부드럽고 대비가 있는 배색입니다.
정사각형 (Tetradic) +90° / +180° / +270°
색상환을 네 등분한 색상들로, 풍부하고 다양한 배색을 만들 수 있습니다.

💡 Tips

  • 보색은 강한 대비, 유사색은 조화로운 느낌을 줍니다.
  • 3색 조화(트라이아드)는 활동적이고 역동적인 디자인에 적합합니다.
  • 생성된 팔레트를 바로 복사해 디자인 도구에 붙여 넣으세요.

자주 묻는 질문

색상 조화란 무엇인가요?

색상 조화는 색상환에서 특정 각도 관계에 있는 색상들을 조합해 시각적으로 균형 잡힌 배색을 만드는 이론입니다.

스와치를 클릭하면 무엇이 복사되나요?

스와치(색상 블록)를 클릭하면 해당 색상의 HEX 코드(예: #FF5733)가 클립보드에 자동으로 복사됩니다.

어떤 색상 조화를 사용하면 좋을까요?

단순하고 강한 대비를 원할 때는 보색, 부드럽고 자연스러운 느낌엔 유사색, 다채로운 디자인엔 삼색이나 정사각형 배색을 추천합니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
