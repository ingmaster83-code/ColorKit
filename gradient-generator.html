자주 묻는 질문

선형과 방사형 그라디언트 모두 생성할 수 있나요?

네, 선형(linear) 및 방사형(radial) 그라디언트를 모두 지원합니다.

생성한 그라디언트의 CSS 코드를 바로 복사할 수 있나요?

네, 생성된 CSS 코드를 복사 버튼으로 바로 복사할 수 있습니다.

색상을 몇 개까지 추가할 수 있나요?

여러 색상 정지점(color stop)을 자유롭게 추가하여 복잡한 그라디언트를 만들 수 있습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
