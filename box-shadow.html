생성된 CSS 코드

💡 Tips

  • x·y 오프셋, 흐림, 퍼짐 값을 조정해 원하는 그림자를 만드세요.
  • inset 옵션을 켜면 박스 안쪽 그림자가 됩니다.
  • CSS 코드를 바로 복사해 스타일시트에 붙여 넣으세요.

자주 묻는 질문

여러 겹의 그림자를 설정할 수 있나요?

네, 여러 box-shadow 레이어를 추가하여 복잡한 그림자 효과를 만들 수 있습니다.

inset 그림자도 생성할 수 있나요?

네, 내부(inset) 그림자 옵션을 선택하여 안쪽 그림자를 만들 수 있습니다.

CSS 코드를 바로 복사할 수 있나요?

생성된 box-shadow CSS 코드를 복사 버튼으로 바로 복사할 수 있습니다.
