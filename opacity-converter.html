💡 Tips

  • HEX 투명도(00~FF)와 CSS opacity(0~1) 간 변환을 지원합니다.
  • RGBA의 alpha 값은 0(완전 투명)~1(완전 불투명) 범위입니다.
  • HEX 8자리 마지막 두 자리가 투명도 값입니다.

자주 묻는 질문

불투명도와 투명도의 차이가 뭔가요?

불투명도(opacity) 100%는 완전히 불투명, 0%는 완전히 투명입니다. CSS rgba()의 알파값과 동일한 개념입니다.

HEX 색상에 투명도를 추가할 수 있나요?

네, HEX 색상 코드에 투명도를 적용한 8자리 HEX(#RRGGBBAA)로 변환할 수 있습니다.

rgba() 형식으로 바로 복사할 수 있나요?

네, rgba() CSS 코드를 클릭 한 번으로 복사할 수 있습니다.
